# Правила проекта «IQ плюс один»

Проект создаётся вместе с ребёнком. Ребёнок придумывает игру, проверяет её и решает, что добавить дальше. Все технические действия агент выполняет самостоятельно.

- Не просить ребёнка пользоваться терминалом.
- Самостоятельно запускать проверки, сборку, Git и публикацию.
- Объяснять прежде всего то, что уже можно увидеть и попробовать в игре.
- Никогда не просить пароль администратора в чате.
